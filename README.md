Ingredient-to-Recipe — The Flagship
An offline-first Flutter app that sees ingredients and suggests recipes. No server. No account. No connection.

<img src="assets/ingredient-to-recipe.png" width="85%" alt="Ingredient to Recipe Mockup" /> </div>
Step

What Happens

Tech

📷

Capture a photo of ingredients on hand

Flutter CameraX

🧠

Dart, Local LLM logic

Stack Flutter Dart TensorFlow Lite Computer Vision Drift Offline-First

Engineering note: Full inference pipeline ships inside the app bundle. Zero network calls means zero telemetry, zero latency variance, and zero cost per request. Private by architecture, not by policy.
